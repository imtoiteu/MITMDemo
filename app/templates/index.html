🦈 Wireshark Quick Reference

Capture all HTTP traffic tcp.port == {{ http_port }}
Only POST requests (credentials, forms) tcp.port == {{ http_port }} && http.request.method == "POST"
See cookies in requests http.cookie
HTTPS (encrypted — nothing readable) tcp.port == {{ https_port }}
Chat messages (follow TCP stream) tcp.port == {{ http_port }} && http contains "content"

💡 Tip: Right-click any HTTP packet → Follow → HTTP Stream to see the full request body.

📋 Demo Walkthrough

  1. Start Wireshark — Select your loopback interface (lo0 on macOS / Loopback Adapter on Windows).
  2. Apply filter — Enter tcp.port == {{ http_port }} in Wireshark's filter bar.
  3. Open the Login page — Go to Login and submit any demo credentials.
  4. Inspect the packet — Find the HTTP POST in Wireshark. Right-click → Follow → HTTP Stream. You will see the username and password in plaintext.
  5. Switch to HTTPS — Open https://127.0.0.1:{{ https_port }}/auth/login and repeat step 3.
  6. Compare — Change the filter to tcp.port == {{ https_port }}. You will see only encrypted TLS records — no readable content.
  7. Repeat for Chat and Banking — Demonstrate that all form data is exposed over HTTP and protected over HTTPS.
